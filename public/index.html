Database & Infrastructure Architecture

ExamSeat AI is architected strictly with Supabase PostgreSQL as the sole authoritative persistence store.

Supabase Project: Connected
Database Engine: PostgreSQL 15+ with UUIDv4 / pgcrypto extensions
Security Architecture: Spring Security 6 with HMAC-SHA256 JWT Token Claims
Seating Algorithm: Deterministic Interleaved Round-Robin with Multi-Department Alternation

Credentials and secrets are managed exclusively through secure environment variables (`SUPABASE_DB_HOST`, `SUPABASE_DB_PASSWORD`, `APP_JWT_SECRET`).
